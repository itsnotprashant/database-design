# Database Design – Grade Division

Hello, this is my first program that I wrote! 

A small Python program for my database design class. It takes student scores and divides them into grades and saves the results in a MySQL database.

## Files

- `grade_division.py` – main program, saves data to MySQL
- `grade_division_console.py` – console version (no database)
- `guessing_game.py` – a number guessing game I made for practice

## How to run

1. Install MySQL and create a database: grade_db
2. Install the connector: `pip install mysql-connector-python`
3. Set your own database password (the one in this repo is a placeholder)
4. Run: `python grade_division.py`
